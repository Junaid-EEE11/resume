## Master’s in Applied Statistics and Data Science

**Jahangirnagar University · Department of Statistics and Data Science**  
**2023–2024 · CGPA 3.79/4.00 · 36 credits**

The program covered probability, sampling, statistical inference, multivariate analysis, research methodology, machine learning, time-series analysis and forecasting, data mining, big data, and categorical data analysis.

### Graduate project

**Predicting Vehicle Prices Using Machine Learning Techniques**

The project analyzed 9,988 vehicle records across 18 fields. Work included data cleaning, missing-value treatment, feature engineering, categorical encoding, outlier handling, and numerical scaling. Engineered features included vehicle age, registration lag, and views per hour.

The report considered linear regression, Random Forest, XGBoost, LightGBM, CatBoost, artificial neural networks, clustering, and content-based recommendation. Random Forest Regressor was selected as the final model.

| Metric | Reported result |
| ------ | --------------: |
| R²     |            0.80 |
| MAE    |         374,433 |
| RMSE   |       1,927,833 |

The most influential reported features were engine capacity, model, vehicle age, kilometers run, and brand.
